# Le Carnet

MVP personnel pour piloter des cours de mathématiques avec des élèves de niveaux différents.

## Utilisation

Ouvrir `index.html` dans un navigateur. Les fiches et séances sont enregistrées dans le navigateur, sur l’appareil utilisé.

## Publication GitHub Pages

1. Créer un dépôt GitHub puis y pousser ces fichiers.
2. Dans **Settings > Pages**, choisir **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`.

Le site ne collecte aucune donnée et ne comporte aucun compte. Les liens de la banque de ressources pointent vers les contenus source ; aucun exercice externe n’est recopié.
